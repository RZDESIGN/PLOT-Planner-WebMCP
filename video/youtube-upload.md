## Title

PLOT — Plan together with WebMCP | The WebMCP Challenge

## Description

PLOT is a shared sprint-planning canvas where people and browser agents turn messy work into a visible, reviewable plan.

Seventeen page-defined WebMCP tools let an agent inspect the board, shape sticky notes into tasks, link dependencies and propose a realistic sprint. Ghost cards preview the changes before a separate apply action. The same React actions serve both the human interface and the tool surface.

Try PLOT: https://plotplanner.xyz/
